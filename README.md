
# AI-Powered Career Recommendation System 🚀

## 📌 Project Overview
The AI-Powered Career Recommendation System is a Python project designed to recommend suitable career paths based on a user's skills.

It compares the user's skills with predefined career requirements, calculates a skill-match percentage, and suggests additional skills for improvement.

## 🎯 Objectives
- Recommend career paths based on user skills.
- Calculate a skill-match percentage.
- Identify matching and missing skills.
- Help users explore potential career opportunities.

## 🛠️ Technologies Used
- Python 3
- Conditional logic
- Functions
- Dictionaries and lists
- Sets and list comprehensions
- Sorting algorithms

## ⚙️ How It Works
1. The user enters skills separated by commas.
2. The system compares those skills with predefined career requirements.
3. A match percentage is calculated for each career.
4. Career recommendations are sorted by match percentage.
5. The system displays matching skills and skills to improve.

## 💻 How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure Python 3 is installed.
4. Open the terminal.
5. Run:

   python main.py
